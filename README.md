# Сервис организации волонтёрских мероприятий (Volunteer Events REST API)

Backend-сервис на базе **Spring Boot 3**, **Spring Security (JWT)**, **Spring Data JPA**, **PostgreSQL** и **Liquibase** для автоматизации набора волонтёров на мероприятия, проверки требований по навыкам, контроля расписания и учёта волонтёрских часов.

## Технологический стек
- Java 17+, Spring Boot 3.4
- Spring Web, Spring Data JPA, Spring Security (JWT)
- PostgreSQL 16, Liquibase (SQL-миграции)
- Springdoc OpenAPI (Swagger UI)
- JUnit 5, Mockito, MockMvc, H2 Database (тестирование)
- Docker Compose

## Запуск проекта

1. Запустите базу данных PostgreSQL через Docker Compose:
   ```bash
   docker-compose up -d
   ```
   *(либо создайте локальную базу данных `volunteer_db` в PostgreSQL)*.

2. При необходимости задайте переменные окружения:
    - `DB_USER` (по умолчанию `postgres`)
    - `DB_PASSWORD` (по умолчанию `postgres`)
    - `JWT_SECRET` (секретный ключ для подписи токенов в Base64)

3. Запустите приложение:
   ```bash
   ./mvnw spring-boot:run
   ```

4. Документация и тестирование API доступны в браузере по адресу:
   `http://localhost:8080/swagger-ui.html`

## Основные возможности и бизнес-правила
- Регистрация и аутентификация с выдачей JWT-токена и разграничением ролей (`COORDINATOR`, `VOLUNTEER`).
- Фильтрация мероприятий по статусу, месту проведения, дате начала и требуемым навыкам с пагинацией.
- Проверка наличия всех обязательных навыков у волонтёра перед подачей заявки.
- Запрет на участие в двух пересекающихся по времени одобренных мероприятиях.
- Автоматическое закрытие набора (`CLOSED`) при заполнении всех мест и повторное открытие (`OPEN`) при отмене одобренной заявки.
- Подтверждение фактического участия (`ATTENDED`) с автоматическим расчётом и суммированием волонтёрских часов в профиле.
- Фоновый планировщик (`@Scheduled`) для автоматического перевода прошедших открытых мероприятий в статус `FINISHED`.
- Выгрузка списка участников мероприятия в формате CSV (`/api/events/{eventId}/export-csv`).
